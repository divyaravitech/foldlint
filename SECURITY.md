# Security policy

FoldLint reads source files and writes reports. It doesn't execute project code or access the network at run time.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's [private vulnerability reporting](https://github.com/divyaravitech/foldlint/security/advisories/new) instead. We aim to acknowledge reports within 3 business days and to ship a fix or mitigation within 30 days.

## Supported versions

Only the latest release gets security fixes.
